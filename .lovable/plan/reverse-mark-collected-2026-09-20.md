# Reverse “Mark collected”

## What will change
- Add an **Unmark collected** bulk action beside **Mark collected** in assignment grading.
- Allow the existing per-student **Collected** checkbox to be cleared when the student has no recorded score.
- Preserve scores, teacher comments, uploaded work, and typed submissions when reversing the status.
- Remove empty submission records created only by the accidental bulk action; restore submissions containing work or notes to their submitted state.

## Verification
- Confirm bulk and individual reversal refresh the roster counts and statuses.
- Confirm scored work cannot be accidentally uncollected.
- Check the project build after the change.
