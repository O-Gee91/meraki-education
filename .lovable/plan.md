# Class Student Report

## Goal
Let teachers open a detailed report by clicking a student in a class roster.

## Changes
- Make each roster name open a wide student report.
- Combine class assignments and assessments into one chronological report, including overdue missing/not-completed work.
- Show item name, type/category, due date, score, percentage, letter grade, and completion status.
- Add an overall current grade and completion summary.
- Let teachers edit assignment and assessment scores inline, saving to the same grade records used throughout the app.
- Keep linked assessment totals synchronized when a teacher edits them from the report.
- Include behavior strikes behind an on/off report toggle.
- Add a print action with a clean parent-conference layout.

## Validation
- Confirm roster selection opens the correct student.
- Confirm edits refresh gradebook and assessment data.
- Confirm missing work, summary values, behavior visibility, and printing remain usable on desktop and mobile.
